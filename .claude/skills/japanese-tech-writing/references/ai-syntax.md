# 翻訳調と文型のカタログ

書く前に読む。語彙は `ai-vocabulary.md`、根拠と機械 lint との対応は `lint.md` にある。ここに並ぶのは、日本語として誤りではないが、英語の構文を透かして読んでいるような文の組み立てと、生成文に偏って現れる文型である。共通の見分け方は「この言い回しを選ぶ必然性が文脈にあるか」で、他の言い方の方が素直に読めるなら直す。

## 翻訳調（英語統語の直訳）

| 型 | 直し方 | Before | After |
|---|---|---|---|
| 無生物主語＋他動詞（この事実は〜を示している、データが〜をもたらす） | 主語を人か状況に戻すか、述語を「〜とわかる」「〜になっている」に変える | この結果は、前提が誤っていたことを示している。 | この結果から、前提が誤っていたとわかる。 |
| 連体修飾の入れ子（〜する〜という〜な〜） | 文を割る。名詞に着くまでに述語を二つ以上くぐらせない | 多くの企業が導入しているが効果を実感できていないという課題を抱える技術だ。 | 多くの企業がこの技術を導入している。ただ、効果を実感できている企業は少ない。 |
| cleft（それは〜である。なぜなら〜だ） | 理由を先に書くか、一文にまとめる | それは単純ではない。なぜなら利害が絡むからだ。 | 利害が絡んでいて、単純ではない。 |
| 〜することができる、〜することが可能だ | 可能形か現在形にする | 作業時間を短縮することができる。 | 作業時間が短縮できる。 |
| 〜という点で、〜という観点から | 〜については、〜で見ると | コストという観点から見ると妥当だ。 | コストで見れば妥当だ。 |
| 〜にとって重要だ、〜にとって不可欠だ | 具体的な必要性として書く（〜には〜が要る） | このプロジェクトにとって合意形成は不可欠だ。 | このプロジェクトは、初期に合意を作れるかどうかで決まる。 |
| 抽象名詞＋持つ（意味を持つ、影響力を持つ） | 〜がある、または効果そのものを書く | この決定は大きな意味を持つ。 | この決定で審査時間が半分になる。 |
| 抽象名詞が運ぶ、〜で効く（仕様が意図を運ぶ） | 実際の変化を書く | 仕様はチームの意図を実装へ運ぶ。 | 仕様があれば、チームの意図を実装に反映できる。 |
| 〜することによって | 〜して、〜すれば | 情報を整理することによって判断が速くなる。 | 情報を整理すると判断が速くなる。 |
| 〜に他ならない、〜であることは間違いない | 根拠を先に書き、述語は普通に言い切る | これは時代の変化の表れに他ならない。 | 利用者の半数が乗り換えた。時代が変わったのだと思う。 |
| サ変名詞＋を行う（検証を行う） | 動詞にする | 移行後に検証を行う。 | 移行後に検証する。 |
| ダッシュ挿入（——つまり〜——） | 括弧にするか二文に分ける | 収束するまで——つまり指摘が出なくなるまで——繰り返す。 | 指摘が出なくなる（収束する）まで繰り返す。 |

## 句読点と文型の癖

| 型 | 見分け方 | 直し方 |
|---|---|---|
| 短い主題の読点 | 文頭 5 文字以内の名詞＋「は」の直後に読点（「結論は、」「要点は、」） | 読点を外す。または主題を長くするか、文を組み替える |
| 読点の多さ | 一文に読点が三つ以上。統語の切れ目にない読点 | 文を分ける。読点は主語の後と従属節の境だけに置く |
| 体言止めの連続 | 短い体言止めが二文以上続く | 山場の一文だけに残し、他は述語で終える |
| 「別物だ」の連発 | 同じ節の 5 文以内に「〜は別物だ」が 3 文 | 何がどう違うかを一度書き、残りは削る |
| 否定→肯定の対比（〜ではなく〜、〜だけでなく〜も） | 全文の 2% を超える。後半だけを読者に見せて意味が通らないなら言い換えに過ぎない | 読者が本当に誤解していそうな一箇所だけ残し、他は肯定文にする |
| 三点構成 | 「大きく分けて 3 つ」「理由は 3 つ」と先に数を宣言する | 論点の数だけ書く。数の宣言は削る |
| 自己ラベルの主題提示 | 「重要なのは」「大切なのは」「ポイントは」で始まる文が文書に 3 回以上 | 主張をそのまま書く |
| 否定文の並列 | 否定文が 2 文続き、短い肯定文で締める（〜ではない。〜でもない。〜だ。） | 肯定文から書く |
| 節頭の予告 | 「本節では〜を説明する」が節ごとに繰り返される | 内容から書き始める。予告は文書に一度まで |
| 段落頭の接続詞 | 段落の 3 割以上が「しかし」「また」「さらに」で始まる | 内容で前段落とつなぐ。接続詞なしで通るなら削る |
| 段落の均質さ | どの段落も同じ文数、同じ長さ | 重要な段落を長く、軽い段落を一文で済ませる |
| 文長の単調さ | 短い文（20 字前後）と長い文（60 字以上）が両方ない | 一番言いたい文を短くし、背景は長く続ける |
| 予告・異変・種明かし・回収の筋 | 説明文なのに「〜と思っていた。ところが〜。実は〜。冒頭の〜がここで効く」という筋書きが走る | 解説・報告・メモ・論文本文では事実の順に書く。読み物に限り `../../cognitive-rhythm-writing/SKILL.md` |

文長の単調さは、コーパス比較で最も弁別力が高かった信号である（`lint.md`）。テンポを整える規範は既存の章にあるので、ここでは機械 lint が指すことだけを書いた。
